You have access to Penpot tools to interact with a Penpot design project directly.
**Precondition:** the user must connect the Penpot design project using the Penpot MCP Plugin (browser), and only one plugin instance should be connected.

**Primary tool:** `execute_code` — run JavaScript in the plugin context with `penpot`, `penpotUtils`, and `storage`.
Read the Penpot High-Level Overview via `high_level_overview` once per session if needed.

**Plugin URL (local):** http://localhost:4400/manifest.json  
**MCP URL (Cursor):** http://localhost:4401/mcp
